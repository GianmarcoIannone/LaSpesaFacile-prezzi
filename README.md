# Listino pubblico LaSpesaFacile

Solo dati pubblici sui prezzi e strumenti autonomi di raccolta. Il codice dell'app e i dati degli utenti non sono inclusi.

Raccolta ogni giorno alle 06:00 italiane (ora legale gestita), oppure avvio manuale della Action. Il file prices-data.json è scaricabile senza credenziali. Nessun servizio a pagamento o segreto necessario.

Fonti e limiti: PRICE-SOURCES.md. Le osservazioni Open Prices e il listino derivato sono distribuiti sotto ODbL 1.0. Disponibilità e prezzi vanno verificati nel negozio.
